# Assignment 2 Requirements and Rubric

This summary is based on the course's `Assignment 2.pdf` and `Assignment 2 Video.pdf` available to the team. The original course PDFs are not redistributed in this repository.

## Required work and submissions

The assignment is a team-based project on **XAI for CNNs**, worth 50 points. Submit by **November 11, 2026, 7:00 pm**:

- All `.ipynb` files used during the investigation.
- One PDF containing all notebook contents.
- Two meme images.
- Presentation slides.
- TBL contribution statement through its separate Canvas submission.

Submit the presentation video by **November 4, 2026, 7:00 pm**. It must be no longer than two minutes, state the group number, be saved in Panopto's `Assignment 2 Videos [assignments]` folder, use the title format `Group # - Title`, and be embedded in the Canvas `Assignment 2 Video` submission.

## Rubric (50 points)

| Criterion | Points | Highest-level expectation |
|---|---:|---|
| Results from classroom XAI methods | 12.5 | Extremely thorough evaluation of multiple methods introduced in class. |
| Results from a new XAI method | 12.5 | Use a method not introduced in tutorials/lectures, justify it, and interpret its results. |
| XAI interpretation | 10 | Insightful interpretation that relates results to the research questions. |
| Report quality | 5 | Complete, well-organized report with figures. |
| Presentation quality | 5 | Entertaining presentation that stays within the time limit. |
| Meme vote | 5 | Score depends on the class vote rank (Top-X: 5; Top-Y: 2.5; otherwise: 0). |

The classroom-XAI rubric also lists lower ratings of 9/7/5/3/0; new-method ratings are 8/4/0 below 12.5; interpretation ratings are 7/5/2/0 below 10; report ratings are 4/2/0 below 5; and presentation ratings are 3/2/0 below 5. Canvas lists threshold values of 7, 8, 6, 4, and 3 respectively for the first five criteria. The assignment PDF does not define how the thresholds are applied or specify the vote counts for Top-X/Top-Y.
